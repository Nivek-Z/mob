# 性能维护与测量

优化须保留 Firefly-Mod 的 24 块首屏拼合、雨幕、卷帘、五场景滚动、图片和交互。不能通过降低雨滴数量、降低画质、减少场景或关闭动效获得收益；操作系统与访客原有的减弱动效选择仍须尊重。另一主题不在本次风格改造范围。

## 已实施的优化

- 首页按场景缓存上一次绘制进度。仍在变化的场景执行原来的插值和绘制公式；进度不变的场景跳过计算和样式赋值。尺寸、主题配置、动效模式变化后失效并重绘，返回页面时重新测量。
- 在尺寸测量阶段记录场景结束位置；雨幕动画和愿望轮播不在写样式之后反复读取 offsetHeight。雨滴数量、画布分辨率和绘制调度不变。
- `/themes/` 保留目录下的公开静态资产直接交给 ASSETS，绑定请求从三次减到一次。该前缀不能声明页面别名。管理资产仍走受保护路径；主题 HTML 保持 Cookie 隔离与私有缓存；原始图片种子仍被 Worker 拦截。
- 公开配置媒体引用索引缓存在 R2 的 `.mob/settings/public-references.json`。**每次先实时读取 GitHub HEAD**，再校验缓存版本、仓库、分支、站点来源、HEAD、大小、ID 与路径结构。快照改变即重建；GitHub 异常不能使用旧权限。首次查询仍扫描当前 Git 快照，后续公开引用查询从五个 GitHub 读取步骤减到一个实时 HEAD。媒体路由还保留文章和图库检查。
- 删除保护始终重新检查全部配置，包括停用主题，不采用公开引用缓存。缓存最大 2 MiB，可删除、重建；没有把配置权威存储迁到 R2。缓存读写异常退回正常仓库扫描。
- 管理后台读取主题配置不再重复请求同一个配置文档；返回值、SHA 和显式媒体引用保持原样。

## 固定动画回放

`test/firefly-motion.test.ts` 使用固定桌面尺寸、几何位置、滚动输入与 RAF 调度，在首屏、雨幕、导览、卷帘、故事和页尾各回放 120 帧。比较所有动画节点的样式、交互状态和场景计数，共 720 个状态，原实现和优化版的 SHA-256 相同：

`33c962b77baf1439c5d70d1e3656dfbafc1156630aa88f5647648ea45646b207`

| 区段（120 帧） | 原样式赋值次数 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| 首屏拼合 | 10,560 | 9,840 | 6.8% |
| 首屏雨幕 | 10,560 | 9,840 | 6.8% |
| 导览 | 10,560 | 82 | 99.2% |
| 卷帘 | 10,560 | 595 | 94.4% |
| 故事 | 10,560 | 119 | 98.9% |
| 页尾 | 10,560 | 0 | 100% |
| 合计 | 63,360 | 20,476 | 67.7% |

回放中的 offsetHeight 读取由 840 次降至 0；尺寸变化时的必要测量仍执行。雨幕区的 120 次绘制、4,320 个雨滴线段保持一致。样式实际变化次数也保持一致，减少的是重复赋值和计算。**这些是脚本工作量，不能解释为 FPS 提升、整站提速或真实浏览器绘制时间。**

复测：

```sh
MOB_PERF_OUTPUT=/tmp/firefly-motion.json npx vitest run test/firefly-motion.test.ts
# 如需重放原实现，先把历史 home.js 导出至本地，再设置 MOB_PERF_SOURCE。
```

## 线上加载测量

同一测试环境、同一 curl 进程复用连接，顺序请求首页、外观配置、文章、活动、首页 JS、同一张自定义封面。两轮预热后取五轮的 TTFB 中位数。分别保存 HTTP 状态、TLS、TTFB、总时间和传输字节，检查测试期间是否有新部署或配置变化。首次连接握手与测试代理耗时不计入复用连接对比。

2026-10-03 的优化前基线：

| 资源 | TTFB 中位数 |
| --- | ---: |
| 首页 HTML | 52.1 ms |
| 外观配置 | 418.9 ms |
| 文章列表 | 242.8 ms |
| GitHub 活动 | 192.0 ms |
| 首页 JS | 51.7 ms |
| 自定义封面 | 1,710.9 ms |

首次快照构建、GitHub 响应速度和 Cloudflare 边缘位置会影响结果；部署后必须按同一方法复测。线上 TTFB 只衡量该资源开始响应的时间，不等于整个首屏加载时间。没有取得真实浏览器 LCP/INP/FPS 时，不得声称改善了这些指标，也不能编造 Lighthouse 分数。

手动线上复测（需要 curl；不得加入离线测试）：

```sh
node scripts/measure-http.mjs https://your-site /media/id/filename /tmp/http.json
```
