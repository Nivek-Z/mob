# 主题作者约定

阅读 `../docs/THEMES.md`；主题输出静态文件。每个主题在 `themes/<id>/` 自定义前台、后台、样式、脚本和专属配置，注册到 `themes.json`。

公共资料、社交/友链、文章封面和图库分类通过核心 API读取，不能保存另一份主题专属公共数据。配置字段与表单由主题自己定义；后台通过声明的配置 API写回自身 config 目录。

首页提供图库与主题选择入口。明暗模式属于主题内部设置，整套主题选择影响当前访客。后台自行实现文章编辑、图床管理、公共与自身设置；使用 SHA 处理冲突，保留未保存输入。

拖入/粘贴图片自动上传、归入文章插图并插入稳定链接；显示进度，失败允许重试。预览私有资源使用鉴权 URL。公开配置不能包含秘密。

支持手机、键盘和减少动效。图片、位置、列表、动效等独有字段完全由主题声明与代码决定，不要求后端认识它们。

性能改善应跳过重复计算和重复赋值，保留原视觉效果与动画公式。场景进度缓存必须在尺寸、配置、动效模式变化后失效并恢复正确样式。不要在动画写样式后读取布局尺寸。验证口径见 `docs/PERFORMANCE.md`。

仓库活动从 /api/activity 读取，通用配置由公共资料设置保存，不能在主题配置复制。主题自行选择图表样式和布局；内置主题显示时区、统计区间、更新时间及过期/失败状态，手机可横向滚动，方块可用键盘与触摸查看日期。不能把加载失败画成全零热力图。
