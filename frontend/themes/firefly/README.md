# 萤火小屋

遵守 ../../AGENTS.md 和 ../../../docs/THEMES.md。本主题独立实现个人展示、首屏拼合、雨幕、卷帘与五幕故事，以及写作台、图床和设置界面。

主题字段声明在 theme.json，外观写回 config/appearance.json：首屏、展示图片、文字/图片贴纸与位置、动效开关和距离、章节、向导、copy 文字选择器映射和 styles 样式映射。管理页自己生成分组表单并提供完整 JSON 编辑；后端不认识上述字段。copy/styles 只用于主题展示，不另存个人资料、社交或友链。

公共资料与导航读取 /api/site；图床与文章调用核心 API。上传资源直接到 R2，默认装饰图从 R2 种子入口提供。后台脚本置于 admin/，直接资产访问也鉴权。静态源码更改需部署，配置保存后 API读取最新文件。
