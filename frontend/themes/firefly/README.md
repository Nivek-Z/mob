# Firefly-Mod

参考 [MmzMing/my-blog](https://github.com/MmzMing/my-blog) 的个人展示风格，保留碎片拼合首屏、雨幕、卷帘与五幕滚动故事。注册显示名为 Firefly-Mod，内部 ID 永远保持 `firefly`，原配置目录与 `/theme-media/firefly/` 地址继续有效。

遵守 ../../AGENTS.md 和 ../../../docs/THEMES.md。公共资料、社交、友链、导航、图床分类和 GitHub 活动统一读取核心 API；主题不能另存一份。主题字段在 theme.json 声明，外观配置写回 config/appearance.json。配置文本由 GitHub 保存，上传图片、音视频字节由私有 R2 保存；浏览器偏好只用于个人明暗模式和简洁浏览。

## 管理界面

本主题独立实现写作台、图床和设置；`admin/ui.js` 与 `admin/admin.css` 是主题自己的组件，不要求其他主题采用。后台脚本通过 `/admin/assets/firefly/` 的鉴权入口访问。

- 设置按首屏、图片、贴纸、动效、旅程、向导等分区。图片可私有预览、上传或从图床选择；列表项目可逐项移除、调整顺序。完整 JSON 编辑保留未知字段；编辑原始 JSON 时暂停表单输入，应用或保存后恢复。
- 公共资料、图床分类、主题切换在同一设置页切换范围。注册变更在部署后生效；现有主题的 ID 和目录只读。
- 写作台提供搜索、草稿筛选、Markdown 工具、写作/对照/预览。拖入或粘贴素材会原位插入占位，成功后替换稳定链接；失败支持原任务重试，未完成占位阻止保存。封面独立选择，不自动把正文第一张图设为封面。
- 图床先浏览卡片、再弹窗编辑。批量分类或权限独立选择「保持」，图库展示必须同时公开链接；应用之后点击保存才写回。R2 未登记素材仍通过扫描与显式纳入管理，默认私有，原对象和链接不变。
- 全部写入携带 SHA。冲突保留输入；切换页面、重新读取及关闭未应用素材弹窗提醒未保存修改。Ctrl/Cmd S 保存当前内容；保存中继续写正文的修改仍标记待保存。

## 前台与验证

手机导航内提供主题选择，文章目录可折叠，图库和正文图片支持键盘放大。首页可直接阅读或选择简洁浏览；系统减少动效、主题总开关优先于访客动效偏好。对话选项不会修改配置对象或覆盖管理员自定义联系链接。

修改后运行 `npm run check && npm test && npm run build`，验证固定样本下的配置冲突、未知字段、编辑器上传占位、保存期间继续输入、图床批量权限和手机入口。不要把生产配置当成测试默认值，不改动用户文章、图床索引或主题外观。
