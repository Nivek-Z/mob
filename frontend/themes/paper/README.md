# 纸间

遵守 ../../AGENTS.md 和 ../../../docs/THEMES.md。本主题使用独立的纸色与阅读排版，拥有自己的文章、标签、图床、关于页与管理界面。

专属声明在 theme.json；config/reading.json 定义强调色、阅读宽度、字号、首页文字与图库入口。设置页采用纸间自己的表单与 JSON编辑；公共资料、社交与友链仍读取统一 /api/site。主题无需依赖其他主题的 CSS或配置。

可选复用 core/ 的传输、上传和 Markdown助手，界面仍由本主题决定。上传文件进入 R2，文本设置写回 GitHub；后台资产置于 admin/并鉴权。
