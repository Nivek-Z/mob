# 后端约定

遵守根 `AGENTS.md`、`docs/PLATFORM.md` 和 `docs/THEMES.md`。

核心定义通用业务模型；主题自定义 JSON 结构与管理界面。仅允许读写注册主题声明的配置文件，不接受浏览器任意指定仓库路径。可选 JSON Schema 用于校验，不能执行主题代码。

公共资料、社交链接、友链全站共用。文本写 GitHub，媒体字节写 R2。配置 API支持运行时读到保存后的值；入口和源码变化仍需部署。

活动接口仅公开日期与提交次数等聚合信息，不能输出提交正文、作者资料或凭据。提交历史分页固定到同一个分支 HEAD，设置总时限与页数上限；超过上限不能返回不完整的“成功”图。旧缓存必须显式标记 stale，数据缺失使用 unavailable；按 docs/ACTIVITY.md 的时区、区间与连续天数口径统计。

直接访问主题的管理资产同样鉴权；根据 Cookie 返回的主题 HTML 使用私有缓存策略。原生 fetch 必须使用正确 receiver。媒体删除检查所有文章、图库状态与全部主题配置引用。

多文件 GitHub 提交保留 SHA 冲突检查。上传成功但文本登记失败时可重试同一 ID；不能回滚删除已被使用的对象。

已登记元数据从 Git 恢复；R2 辅助记录缺失不应阻断稳定链接、私有预览、引用校验或删除。删除先保留可重试记录再撤销图库授权。上传状态清理有界分页，经协调器处理，不删已完成文件；取消状态至少保留一天。

已有 R2 素材扫描排除 .mob/、cache/ 和未完成上传。只有管理员可预览原始对象。纳入原始素材验证受支持 MIME、大小、文件头与 ETag；保留原始对象，按源 key/ETag 派生副本 ID并校验来源摘要，避免重复复制和意外覆盖。不能把 GET 扫描当成图库登记或公开授权。
